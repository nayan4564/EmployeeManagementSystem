# Employee Management System

## Requirements
- JDK 17+
- Maven (or use Maven wrapper generated by your IDE)
- SQL Server with TCP/IP enabled and a login allowed to connect
- Eclipse/IntelliJ

## Database setup
Run `database/EmployeeManagementDB.sql` in SSMS. Then update `src/main/resources/application.properties` with your SQL Server username/password and instance/port.

## Run
Import the folder as an Existing Maven Project, wait for dependencies, then run `EmployeeManagementApplication.java`.
Open http://localhost:8080
Initial admin: `admin` / `Admin@123` (change immediately for any real deployment).

## Features
Admin login, dashboard, employee create/list/edit/delete, department management, attendance entry/list, salary entry/list with net salary calculation, and leave request approval/rejection.

## Notes
This is an educational starter project. For production, add CSRF-safe POST actions for destructive operations, role management, audit logs, stronger validation, pagination, password reset, and employee self-service authorization. Do not deploy with the sample password.
